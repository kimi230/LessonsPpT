## Big Picture: 모듈 사고

```
┌─────────────────────────────────────────────────────┐
│                   워크플로우 정의                       │
│         (어떤 모듈을 언제 쓰는가 = 생산성 차이)          │
└──────────┬──────────────┬──────────────┬────────────┘
           │              │              │
    ┌──────▼──────┐ ┌─────▼──────┐ ┌────▼─────────┐
    │  LLM 모듈   │ │ 컴퓨팅 모듈 │ │  도구 모듈    │
    │             │ │            │ │              │
    │ · 비결정론적  │ │ · 결정론적  │ │ · 검색/파일   │
    │ · 확률 분포  │ │ · 정확/반복 │ │ · 코드 실행   │
    │ · 언어/추론  │ │ · 고속 처리 │ │ · 문서 작성   │
    │ · 요약/분류  │ │ · DB/ETL   │ │ · 데이터 분석  │
    └─────────────┘ └────────────┘ └──────────────┘
```

---

## 한 장 슬라이드 메시지

1. **LLM** = 확률적 함수 모듈 + 도구를 쓰는 오케스트레이터
2. **컴퓨팅** = 정확/검증/반복 실행 모듈
3. **생산성** = 워크플로우 정의 + 모듈 조합 + 컨텍스트/데이터 품질
4. **리스크** = 프라이버시/컴플라이언스/환각/편향 → 정책 + 검증으로 관리
